# Android Notes

Notes I take while working through Android problems. Mostly written for
myself, made public in case they save someone else time.

Current focus is AI coding agents on Android codebases. There is a lot
written about agents in general and very little about what actually
happens when you point one at a Gradle project with real tests and a
real emulator.

I have been building Android apps for about fifteen years, most of that
on large consumer apps.
